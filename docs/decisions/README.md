# Decisions

Short records of decisions already made, following the Kent C. Dodds / Kody convention.

Each decision is one file named `NNNN-short-title.md`, starting at `0001`. Take the next number for a new decision. Do not renumber old files.

A record is about half a page and has:

- **Status** and **Date**
- **Context**: the situation that forced the choice, written after the decision was made
- **Decision**: what was chosen, in a sentence or two
- **Consequences**: what follows, including a revisit-if when there is a concrete condition that would reopen it

These are not design docs in progress, and not a note for every change.
