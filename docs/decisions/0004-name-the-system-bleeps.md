# 0004: Name the system Bleeps

- **Status:** superseded by [0010](0010-bleeps-runs-the-crew-bloops-reflects.md)
- **Date:** 2026-11-12

## Context

The brand is already Bleeps and Bloops. The docs called the pipeline "the factory", which left no word for the system itself and no word for what it ships. Kent C. Dodds names his system Kody. This system needs the same kind of name.

## Decision

Bleeps is the system. Bloops are what it produces: shipped pull requests and features. Bleeps and Bloops is the brand.

## Consequences

- Docs and agents say Bleeps for the system and bloop for a result it shipped.
- The site, the domain, and the repo stay under the Bleeps and Bloops brand.
- **Revisit if:** the name collides with a product we ship, or James picks a different name for the system.
