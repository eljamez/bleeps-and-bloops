# Vision

Bleeps is a ticket-to-merge pipeline, built for Orca. It also goes looking: a scout files issues and runs them through the same pipeline. Orca's `issueCommand` kicks off a ticket, an agent builds the feature, Blip owns the tests, automatic review runs, and auto-merge to `develop` is possible when the tests passed. A shipped pull request or feature is a bloop.

Maximize automation for web and mobile apps. The human steers. Agents do the work.
