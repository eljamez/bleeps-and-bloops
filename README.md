# Bleeps and Bloops

This repository is the home of the Bleeps and Bloops software factory ([bleepsandbloops.com](https://bleepsandbloops.com)).

Bleeps is the system. It does the work. Bloops are the results: shipped pull requests, features, and other outputs. The name of the whole thing stays Bleeps and Bloops.

The public site lives in [`site/`](site/). It is a Next.js app. On Vercel, set the project **Root Directory** to `site/`.

```bash
cd site
npm install
npm run dev
```

`npm run build` runs in `site/` as well.

The factory is being rebuilt from scratch. The previous website code lives on the `legacy` branch.

The plan is in [docs](docs/README.md).
